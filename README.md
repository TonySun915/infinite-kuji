# 無限賞抽獎

個人使用的「無限賞」抽獎模擬 App（純前端單頁，無後端、無帳號）。

🌐 系統網址 👉 https://tonysun915.github.io/infinite-kuji/

## 📱 一、iPhone 安裝方式（Safari 加入主畫面）

1. 使用 **Safari** 開啟系統網址（⚠️ 請勿使用 LINE、Chrome 或其他瀏覽器）
2. 點擊 Safari 底部的「分享」按鈕（⬆️）
3. 選擇「加入主畫面」
4. 確認名稱後，點擊「加入」

## 🤖 二、Android 安裝方式（Chrome 加入主畫面）

1. 使用 **Chrome** 開啟系統網址
2. 畫面上方或選單中會出現「加入主畫面」提示
3. 若未自動顯示，點擊右上角「⋮」→「加入主畫面」
4. 確認後加入

## 🔔 使用說明

- 桌面會出現「無限賞」圖示，點擊後以全螢幕 App 模式開啟
- 第二次之後可在離線狀態使用
- 抽獎紀錄、餘額都存在各自裝置的瀏覽器裡，手機與電腦不互通
- 更新版本後，若手機沒變新，關閉 App 重開一次即可

## 🎰 規則

| 項目 | 內容 |
| --- | --- |
| 超神款機率 | 每抽 0.5%，每抽獨立 |
| 保底 | 連續 500 抽沒中超神款，第 500 抽必中，中獎後歸零 |
| 超神款獎項 | 中超神款後再從 24 項獎池抽一項，越貴機率越低 |
| 基本款 | 沒中超神款時皆為基本款（寶可夢卡牌，價值 NT$1） |
| 抽數 | 1／3／5／12 抽，每抽 NT$65 |

## 💰 錢包控制

開啟 `wallet.html`（網址後面加 `wallet.html`）可以調整點券、鑽石、優惠券，主頁面會即時同步。

## 🛠 檔案說明

- `index.html`：主程式（含圖片，單檔）
- `wallet.html`：錢包控制頁
- `manifest.webmanifest`、`sw.js`、`icon-*.png`：加入主畫面與離線用

本專案僅供個人娛樂，所有抽獎皆為隨機模擬，不涉及任何真實金錢或商品交易。商品名稱與圖片屬原權利人所有。
